# NutriSnap Technology Stack

## Frontend (User Interface)
- **Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **HTTP Client:** Axios

## Backend (Server-side Logic)
- **Framework:** FastAPI
- **Server:** Uvicorn
- **Database:** SQLite + SQLAlchemy
- **Language:** Python 3.9+ 
- **Async:** asyncio + aiosqlite

## ML/AI Models & Frameworks
- **Detection:** YOLOv8 (PyTorch)
- **Portion Estimation:** XGBoost
- **Depth Estimation:** Depth Anything V2 (PyTorch/Transformers)
- **Segmentation:** SAM (PyTorch)

## Data & Utilities
- **Image Processing:** OpenCV, Pillow, NumPy
- **Data Validation:** Pydantic
- **Configuration:** YAML
