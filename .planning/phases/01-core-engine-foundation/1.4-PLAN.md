# Plan 1.4: Manual Logging & Database Setup

**Goal**: Enable users to log meals manually using a searchable food database.

## User Review Required
> [!NOTE]
> We will start with a local JSON-based food database before integrating external APIs like USDA in later stages.

## Proposed Changes

### [NEW] `server/api/meals.py`
- Endpoints: `POST /meals` (log), `GET /meals` (history), `GET /meals/search` (lookup).

### [NEW] `data/food_database.json`
- Initial list of 100+ common foods with calories/macros per 100g.

### [NEW] `web/src/components/MealLogger.jsx`
- Frontend component for searching and logging meals.

## Verification Plan
### Automated Tests
- CRUD tests for meal logging in MongoDB.

### Manual Verification
- Search for "Banana" in the UI, log a 150g portion, and verify it appears in the daily summary.
