# Plan 1.2: Model Wrapper Service

**Goal**: Integrate the existing mass estimation model into the FastAPI backend.

## User Review Required
> [!WARNING]
> This stage requires the model checkpoints (EfficientNet, SAM2, GLPN) to be present in the `models/checkpoints/` directory.

## Proposed Changes

### [MODIFY] `server/main.py`
- Implement `lifespan` event to load models on startup.
- Define `POST /predict` endpoint for image uploads.

### [NEW] `server/services/inference.py`
- Wrapper class for the multi-stage pipeline:
  1. Preprocessing (Resize, Normalization).
  2. SAM 2 Segmentation.
  3. GLPN Depth Estimation.
  4. EfficientNet Mass Prediction.

### [NEW] `server/core/constants.py`
- Food density lookup table (JSON or Dict) for mass-to-calorie conversion.

## Verification Plan
### Automated Tests
- Mock inference test using a dummy 5-channel tensor.

### Manual Verification
- Upload a sample image via Swagger and verify the JSON response contains `mass_g` and `calories_kcal`.
