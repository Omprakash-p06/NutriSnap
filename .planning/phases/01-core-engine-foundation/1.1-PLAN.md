# Plan 1.1: Project Scaffolding

**Goal**: Establish the base directory structure and boilerplate for both backend and frontend.

## User Review Required
> [!IMPORTANT]
> This plan will initialize the `server/` and `web/` (or similar) directories. Ensure no critical files are overwritten if you've already started.

## Proposed Changes

### [NEW] Backend Scaffold
- `server/main.py`: Entry point for FastAPI.
- `server/core/config.py`: Environment configuration.
- `server/core/database.py`: MongoDB connection logic.
- `server/requirements.txt`: Backend dependencies.

### [NEW] Frontend Scaffold
- `web/`: Vite + React 19 project.
- `web/vite.config.js`: PWA plugin configuration.
- `web/src/App.jsx`: Basic layout with view switching.

## Verification Plan
### Automated Tests
- `pytest` for checking FastAPI health endpoint.
- `npm run build` for verifying Vite production build.

### Manual Verification
- Access `http://localhost:8000/docs` to see Swagger UI.
- Verify PWA manifest is served at `http://localhost:5173/manifest.webmanifest`.
