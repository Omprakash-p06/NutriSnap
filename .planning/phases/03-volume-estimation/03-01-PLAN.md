## Objective

Build the foundation for volume estimation by implementing a `VolumeEstimator` adapter and the core logic for projecting masked RGBD data into 3D metric point clouds using camera intrinsics. This establishes the interface for downstream geometric volume calculation.

**Create `src/nutrisnap/pipeline/volume.py`** with base class and projection logic:
```python
import numpy as np
from pathlib import Path
import yaml
from typing import Optional, Dict

class VolumeEstimator:
    def __init__(self, config_path: str | Path = "configs/pipeline/volume.yaml"):
        with open(config_path) as f:
            self.config = yaml.safe_load(f)
        self.intrinsics = self.config['intrinsics']

    def project_to_pc(self, depth: np.ndarray, mask: np.ndarray) -> np.ndarray:
        """Project masked depth to 3D point cloud (meters)."""
        v, u = np.where(mask > 0)
        z = depth[v, u]
        
        # Filter invalid depth
        valid = (z >= self.config['processing']['min_depth']) & \
                (z <= self.config['processing']['max_depth'])
        v, u, z = v[valid], u[valid], z[valid]
        
        if len(z) == 0:
            return np.zeros((0, 3))

        fx, fy = self.intrinsics['fx'], self.intrinsics['fy']
        cx, cy = self.intrinsics['cx'], self.intrinsics['cy']
        
        x = (u - cx) * z / fx
        y = (v - cy) * z / fy
        
        return np.column_stack((x, y, z))
```
