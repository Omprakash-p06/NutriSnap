# Plan 04-02: Training Loop & Fold Management

Implement a robust training loop that manages 5-fold cross-validation, checkpointing, and hardware optimization (AMP + Grad Accumulation).

## Objective

Deliver a training script that can reproducibly train the nutrition regressor under a 4GB VRAM constraint.

## Must Haves

- [ ] `NutritionTrainer` class in `src.nutrisnap.training.trainer`.
- [ ] Support for Mixed Precision (`torch.cuda.amp`).
- [ ] Gradient Accumulation logic to handle tight VRAM.
- [ ] Automatic K-Fold loop using Phase 1 splits.
- [ ] Progress logging (TensorBoard or simple logger).
- [ ] Checkpointing at best val-loss per fold.
