# Plan 04-03: Ensemble Inference & Packaging

Package the trained fold weights into a unified ensemble predictor that can be consistently used for evaluation on the test set and production inference.

## Objective

Create the `NutritionPredictor` that handles ensembling (averaging) of the 5-fold models to provide a lower-variance nutrition estimate.

## Must Haves

- [ ] `NutritionPredictor` class in `src.nutrisnap.pipeline.inference`.
- [ ] Load 5-fold weights from `models/checkpoints/`.
- [ ] Implement `predict(rgbd_tensor, scalar_tensor)` returning averaged [cal, fat, carb, protein].
- [ ] Evaluation script `scripts/evaluate_ensemble.py` to calculate final test metrics.
- [ ] Hardware-safe inference (zero_grad, eval mode, CPU-bound post-processing).
