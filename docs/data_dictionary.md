# NutriSnap Data Dictionary

*Last updated: 2026-04-11 | Phase 1: Foundation & Data Contracts*

This document describes all data assets used by the NutriSnap pipeline.

---

## Raw Data (`data/raw/archive (4)/`)

### dish_nutrition_values.csv

The primary nutrition annotation file. Each row is one dish scan.

| Column | Type | Example | Description |
|--------|------|---------|-------------|
| dish_id | str | `dish_1561662216` | Unique 18-char dish identifier: `dish_[unix-timestamp]` |
| calories | float | 300.79 | Total kcal for the entire dish |
| mass | float | 193.0 | Total plate mass in grams |
| fat | float | 12.38 | Total fat in grams |
| carb | float | 28.21 | Total carbohydrates in grams |
| protein | float | 18.63 | Total protein in grams |

**Notes:**
- Mapping to Internal: `calories` -> `total_calories`, `mass` -> `total_mass`, etc.
- Multi-row structure: Dish scans can have multiple rows if ingredient breakdown is present. Summary row is filtered by `total_calories > 0`.
- Calorie range across dataset: approximately 50–1500 kcal.

### dish_ingredients.csv

Per-ingredient breakdown for each dish scan.

| Column | Type | Description |
|--------|------|-------------|
| dish_id | str | Foreign key -> dish_nutrition_values.csv |
| ingredient_name | str | Ingredient name (e.g., "boiled_rice", "chicken_breast") |
| ingredient_grams | float | Weight of this ingredient in grams |
| ingredient_calories | float | Calories contributed by this ingredient |

## Raw Imagery (`data/raw/archive (4)/imagery/`)

### realsense_overhead/
Overhead RGB-D images captured with an Intel RealSense camera.
- One subdirectory per dish_id OR images named with dish_id prefix
- RGB: `.jpg` or `.png`
- Depth: 16-bit PNG, values in millimeters (0–10000 range, 1000 = 1m)

## Interim Data (`data/interim/`)

### dishes.csv
Produced by `scripts/ingest_nutrition5k.py`. One row per unique dish with canonical naming.

| Column | Type | Description |
|--------|------|-------------|
| dish_id | str | Unique dish identifier |
| total_calories | float | Total kcal |
| total_mass | float | Total grams |
| total_fat | float | Total fat (g) |
| total_carb | float | Total carbs (g) |
| total_protein | float | Total protein (g) |

## Split Artifacts (`data/splits/`)

All split files are generated by `scripts/generate_splits.py` from `data/interim/dishes.csv`.
Splits are **grouped by dish_id** and **stratified by calorie bins** `[0, 200, 400, 600, 800, 1000, 2000]`.

### train_ids.txt
One `dish_id` per line. ~70% of all dishes. Disjoint from `test_ids.txt`.

### val_ids.txt
One `dish_id` per line. ~15% of train dishes.

### test_ids.txt
One `dish_id` per line. ~15% of all dishes. Held-out evaluation set.

### mvp_subset_ids.txt
One `dish_id` per line. 8 dishes selected to span the calorie range.

### cv_folds.json
JSON artifact with 5-fold cross-validation assignments.
