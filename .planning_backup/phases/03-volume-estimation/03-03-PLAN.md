# Plan 03-03: Benchmarking & Feature Export

## Objective

Close Phase 3 by creating a batch processing script that extracts volume and area features for all artifacts in the Nutrition5k MVP subset. These scalar features will be stored in a features manifest and loaded by the `NutriSnapDataset` for input into the Phase 4 nutrition regressor. Verification includes a VRAM/timing benchmark to confirm the 2-second inference goal.

## Must Haves

- [ ] `scripts/generate_volume_features.py` script implemented.
- [ ] Features stored in `data/processed/features/volume_features.csv`.
- [ ] `NutriSnapDataset` updated to load these scalar features alongside RGBD tensors.
- [ ] Benchmark report showing average volume-estimation time per image.
- [ ] `Makefile` updated with `volume-features` target.
