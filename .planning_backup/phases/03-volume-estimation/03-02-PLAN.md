# Plan 03-02: Hybrid Volume Calculation (CH + Alpha)

## Objective

Implement the core geometric volume estimation logic using a hybrid approach. For robust results on diverse food shapes (convex like an apple vs. concave like a bowl of soup), the system will compute both Convex Hull and Alpha Shape volumes and use selection logic to choose the most realistic estimate.

## Must Haves

- [ ] `scipy` and `alphashape` added to project dependencies.
- [ ] `VolumeEstimator.estimate_volume(pc)` method implemented.
- [ ] Hybrid selection logic: choose Alpha Shape if its volume is significantly lower than Convex Hull (indicating high concavity).
- [ ] Surface area (2D projection) calculation.
- [ ] Quality metric (e.g., point density, fill ratio) to flag low-confidence estimates.

      v_ch = self.compute_convex_volume(pc)
      v_as = self.compute_concave_volume(pc, alpha=10.0)
      # Switcher logic
      if v_as / v_ch < 0.7:
          return v_as, "concave"
      return v_ch, "convex"
