# Plan 05-01: Regression Diagnostics & Failure Detection

Implement a dedicated diagnostic suite to detect model collapse (constant prediction), overfitting, and systematic bias.

## Objective

Ensure the model is learning real patterns and provides reliable statistical diagnostics for every candidate model produced in Phase 4.

## Must Haves

- [ ] `scripts/evaluate_diagnostics.py` script.
- [ ] Visualization: Predicted vs Actual Scatter and Residual vs Fitted plots.
- [ ] Variance Diagnostic: Flag if `Var(Pred) / Var(Actual) < 0.1`.
- [ ] Rank Correlation: Spearman Rho metrics.
- [ ] Binned Error Analysis: MAE/MAPE split by calorie buckets (<200, 200-800, >800).
