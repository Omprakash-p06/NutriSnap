# Plan 04-01: Nutrition Regressor Architecture

Implement the core multi-modal regression architecture using a 4-channel ResNet18 backbone and late-fusion scalar integration.

## Objective

Create a production-ready PyTorch model that accepts (RGB + Depth) images and scalar features (volume, area) to predict nutritional macros [Calories, Fat, Carb, Protein].

## Must Haves

- [ ] `NutritionRegressor` class in `src.nutrisnap.models.nutrition_regressor`.
- [ ] 4-Channel input adapter for ResNet18.
- [ ] Late-fusion head concatenating CNN features and scalar features.
- [ ] Configurable hidden layers and dropout for regularization.
- [ ] Validation in a script or test to confirm tensor compatibility.
